# Project Statement

## Title

Zara Clothing Inventory Management System

## Problem Statement

Clothing retail stores usually have hundreds of products that can be categorized in dozens of ways. The ability to keep track of inventory availability, avoid selling out-of-stock items, record customer orders, etc. can become challenging for any business that relies on manual processes and paper spreadsheets. Some of the possible issues that can arise are listed below:

• Selling items that are out of stock

• Failing to notice the low inventory of popular products

• Forgetting the already purchased items with their sizes, colors, and other features

• Not having a reliable source of information about the business’s activity

It is essential to implement a system that would allow a small clothing store or even a single employee to keep track of the items available and the ones already sold with minimal hassle.

## Objective

The objective of this project is to design and develop a Python-based command line Inventory Management System for Clothing Retail Stores with the following features:

1. Creation and management of clothing products (category, size, color, price, quantity)

2. Monitoring of stock quantities

3. Notification of low stock products

4. Processing of the customer orders with automatic quantity reduction

5. Viewing of all the customer orders

6. Logging of all significant operations

## Scope of the Project

The following items are within the scope of this project:

• Development of clothing inventory management system in Python with a terminal-based interface

• Using SQLite as a database engine (no remote server)

• Implementation of basic Create, Read, Update, Delete operations for products

• Order processing with direct stock reduction

• Low stock notification mechanism

• Basic logging of events to a file

The following items are outside of the scope for this project:

• Graphical User Interface (GUI)

• Multi-user authorization and authentication

• Hosting of the database

• Processing of payments

• Hardware components such as barcode scanners

• Multi-store inventory management

## Target Users

The target users of this application can be divided into three groups:

1. Clothing store owners and their employees that seek to improve their operations by automating some of the critical business processes

2. Python developers that want to see and use an example of a multi-file application that uses relational database

3. Students or self-learners that want to improve their Python, databases, and Object Oriented Programming skills by studying this project

## Tools and Technologies

The following tools and technologies will be used for this project:

Component Technology

Programming Language Python 3

Database SQLite (sqlite3)

Interface Terminal

Logging Logger (writing to a file)

## Expected Outcome

As a result of this project, there is expected to be a working Python application that consists of multiple files (`app.py`, `database.py`, `product.py`, `inventory.py`, `order.py`, `logger.py`) that together demonstrate the functionality of an Inventory Management System applicable to a small clothing retail store. The application will be written in Python and utilize SQLite for data storage and management and will be able to run on any computer with Python installed.
